# Sticker-generation recovery behavior

A reserved-matte postcondition failure is a generated-pixel failure after the bounded local repair path has already run. The paid source remains checkpointed for diagnosis, but the active production run must not wait for a manual click.

The replacement policy classifies this failure as requiring fresh artwork. After the other parallel workers finish, the normal bounded replacement loop regenerates only the failed slot, reruns local processing and QA, and continues to packaging once the requested approved inventory is complete.

Transient browser/tool failures such as an unavailable Canvas remain local-only and do not automatically spend another image request.
